# ♈♉♊♋♌♍♎♏♐♑♒♓ 🔮✨ Zodiac Sign Explorer Project ✨🔮

## 🌟📌 Overview

The Zodiac Sign Explorer Project is a Python application that retrieves zodiac sign information from the web and displays it through an interactive menu-driven interface. 🌙⭐

Using web scraping techniques, the program collects zodiac sign data including:

🔹 Birthday Ranges 🎂  
🔹 Personality Traits 😄  
🔹 Strengths 💪  
🔹 Weaknesses ⚠️  
🔹 Likes ❤️  
🔹 Dislikes 👎  
🔹 Compatibility 💕  

Users can explore all zodiac signs, learn more about a specific sign, discover their own zodiac sign based on their birthday, and view compatibility information. 🔭✨
