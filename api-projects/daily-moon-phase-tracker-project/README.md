# 🌙 ✨ Moon Phase Tracker ✨ 🌙

## 📌 Overview

Moon Phase Tracker is a Python console application that allows users to view moon phase information for different dates. The program retrieves moon phase data from an online source and displays detailed information about the moon, including illumination, moon age, moon angle, moon distance, and more.

The application also includes ASCII art representations of each moon phase to provide a more visual and user-friendly experience.

---

## ✨ 🌕 Features 🌕 ✨

✅ View today's moon phase

✅ View moon phases for the current week

✅ View moon phases for the next week

✅ Look up the moon phase for a specific date

✅ Display detailed moon phase information

✅ Display ASCII art for each moon phase

✅ Menu-driven interface

## 📋 🌟 Menu Options 🌟 📋

When the program starts, the following menu is displayed:

```text
1. View today's moon phase
2. View moon phases for the week
3. View moon phases for the next week
4. Look Up a specific date
5. Exit
```

### 🌙 Option 1

Displays today's moon phase and detailed moon information.

### 📅 Option 2

Displays moon phase information for every day of the current week.

### 🗓️ Option 3

Displays moon phase information for every day of the next week.

### 🔎 Option 4

Allows the user to enter a date in the format:

```text
YYYY-MM-DD
```

and view the moon phase information for that date.

### 🚪 Option 5

Exits the application.
